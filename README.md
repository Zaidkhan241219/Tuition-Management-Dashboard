# Tuition Management Dashboard

A Power BI dashboard built to track fee status, attendance, and academic performance for a personal tuition business managing 60+ students — automating a process that was previously handled manually in Excel.

## 🔧 Tools Used
- Microsoft Excel (multi-sheet system, formulas, conditional formatting)
- Power BI (dashboard & visualization)

## 📊 What This Project Does
- Designed a multi-sheet Excel system tracking admissions, monthly/yearly fee status, and test performance
- Automated PAID / UNPAID / LEFT status using formulas instead of manual updates
- Built a Power BI dashboard with:
  - KPI cards (Total Students, Active Students, Left Students, Active Fees)
  - Standard-wise (class-wise) student distribution chart
  - Status distribution (Active vs Left) pie chart
  - Morning/Evening batch split donut chart
  - Standard and batch-mode slicers for filtering

## 🔑 Key Insights
- 92% student retention rate (58 Active out of 63 total students)
- Evening batch had a higher enrollment share than Morning batch
- 4th standard had the highest number of enrolled students

## 🔒 Data Privacy
All student names were anonymized (e.g., "Student 1", "Student 2") and contact information was removed before this dataset was used for portfolio purposes.
